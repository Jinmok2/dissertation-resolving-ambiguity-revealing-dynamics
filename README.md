# Resolving Ambiguity, Revealing Dynamics: Computational Approaches to Funding Analysis in Library and Information Science

This repository provides the code, datasets, and analytical outputs
associated with my PhD dissertation at the University of Illinois
Urbana-Champaign.

## Repository Structure
- chapter_2: Organization Name Disambiguation
- chapter_3: Funder Dynamics Analysis
- chapter_4: Gov/Non-gov Co-Funding Analysis

## Data Availability
Original Scopus and Web of Science metadata cannot be publicly
redistributed due to licensing restrictions.

## Reproducibility
The repository provides analysis scripts, model configurations,
and results to support traceability and reproducibility.
